# Format Specifications & Frameworks

## 1. Cấu trúc Carousel (5–8 Slides, kích thước 1080x1350 px)
- **Slide 1 (Cover / Hero Slide):**
  - Chứa Hero Word hoặc Hook Visceral-Parallel ngắn gọn, gây tò mò thị giác.
  - Phân tầng text: Nhãn phụ góc trên-trái (`Montserrat`), Headline chính (`Barber Fill`), Phụ đề dưới (`DM Sans`).
- **Slide 2..N (Content & System Breakdown):**
  - Mỗi slide chỉ giải quyết 1 ý duy nhất.
  - Cấu trúc: 1 Headline ngắn (tối đa 8 từ) + 2–3 dòng body ngắn làm rõ nguyên nhân/giải pháp + chỉ dẫn visual (sơ đồ, icon hoặc bối cảnh).
- **Slide Cuối (Closing CTA):**
  - Kêu gọi hành động trực tiếp: Lưu lại bài viết (`Save`) hoặc Nhắn tin từ khóa (`DM <KEYWORD>`).
  - Font: `Barber Fill` kết hợp nền `#0B1B3D` hoặc `#EDE0C8`.

## 2. Cấu trúc Reel (4–6 Frames / Cảnh, kích thước 1080x1920 px)
- **Frame 0 (Thumbnail / Cover):** Khung hình mở đầu chứa Hero Word rõ nét.
- **Frame 1 (Hook, 0–5s):** On-screen text tương phản mạnh + Voiceover trực diện gợi cảm xúc.
- **Frame 2..4 (Core Value / System in action):** On-screen action (thao tác trên Notion, quy trình vận hành, hoặc bối cảnh làm việc tối giản) kèm phân tích.
- **Frame Cuối (Resolve & CTA):** Giải quyết căng thẳng mở đầu và hiển thị keyword kêu gọi hành động.

## 3. Cấu trúc Static (1 Image, kích thước 1080x1350 px)
- **Visual:** Bố cục tối giản, phân chia tỷ lệ 1/3 (Headline `Barber Fill` đặt ở 1/3 phía trên, hình ảnh bối cảnh/khoảng trắng ở 2/3 còn lại).
- **Caption:** Toàn bộ giá trị nằm ở Caption được trau chuốt theo cấu trúc: Hook -> Vấn đề -> Giải pháp hệ thống -> CTA.

## 4. Cấu trúc Story (3–5 Frames, kích thước 1080x1920 px)
- Phù hợp chia sẻ hậu trường, khảo sát ý kiến (Story Poll), chia sẻ nhanh mẹo vận hành hàng ngày.
