# Hướng Dẫn Chạy Web App MVP (RUN.md)

> Cách mở và trải nghiệm ứng dụng Web App MVP trong ≤ 3 thao tác đơn giản.

---

## 1. Chạy trực tiếp trên Trình duyệt (Không cần cài đặt Node.js)
1. Mở thư mục [`app/`](./app/).
2. Nhấp đúp chuột vào tệp [`index.html`](./app/index.html) (hoặc click chuột phải ➡️ *Open with Google Chrome / Microsoft Edge*).
3. Giao diện Web App MVP sẽ hiển thị ngay lập tức với đầy đủ tính năng!

---

## 2. Hoặc Chạy bằng Local Web Server (Tùy chọn)
Nếu muốn chạy qua Local Server:
```bash
# Di chuyển vào thư mục app
cd "d:/TRANG/Knowledge Hub/Antigravity/Antigravity Test/hocvien_k1_aiautomation/08-capstone/Trang Nguyen Capstone/d3-mvp/app"

# Chạy server với Python (hoặc npx serve)
python -m http.server 3000

# Mở trình duyệt truy cập: http://localhost:3000
```
